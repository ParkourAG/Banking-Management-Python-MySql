Bank Management System(BMS):

# Project Overview:-
The Bank Management System is a desktop application developed using Python, Tkinter, Pandas and MySQL. It is designed to automate daily banking operations by providing a user-friendly graphical interface for administrators, officers, and customers.
The application maintains customer account information, transaction history, and administrative records while ensuring secure access through role-based authentication.

# Features:-
    # Administrator Module
        Create administrator accounts
        Re-Activate Blocked or, Deleted administrator accounts
        Block administrator accounts
        Delete administrator accounts
        View all administrator accounts
        Search administrators

    # Officer Module
        Login with secure credentials
        Create customer accounts
        Re-Activate Blocked or, Deleted customer accounts
        Block customer accounts
        Delete customer accounts
        Search customer accounts
        View customer information
        View all customer accounts

    # Customer Account Management
        Unique account ID generation
        Store customer details
        Account activation/deactivation
        Balance management
        Secure login credentials

    # Banking Operations
        Deposit money
        Withdraw money
        Automatic balance updates
        Transaction recording
        Transaction history viewing

    # Database Features
        MySQL database integration
        Secure data storage
        CRUD operations
        Transaction management
        Account status management
